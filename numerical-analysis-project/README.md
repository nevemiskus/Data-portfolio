# Numerical Analysis Academic Project 

# Objective
Research and use various numerical methods to solve initial value problems. 

# Tools Used
Matlab 

# Data
Provided by the prompt of the project 

# Analysis Steps
- Implement logistic method 
- Implement Euler's method 
- Implement Runge-Kutta 4th order 

# Key Insights
- Euler's method allows for step-size approximations 
- Changing variables such as parameters and initial conditions allows us to visualize the effects 
- Euler's method is generally more unstable than RK4, unless computing significantly small step-sizes
