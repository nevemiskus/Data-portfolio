# Food Insecurity Analysis

# Objective
Analyze customer sales data to identify purchasing trends and retention behavior.

# Tools Used
Excel, R

# Data
Customer transaction dataset (sample/public data)

# Analysis Steps
- Cleaned and organized sales data
- Analyzed repeat customer behavior
- Identified seasonal sales trends

# Key Insights
- Repeat customers drove majority of revenue
- Sales peaked in Q4
- Certain customer segments had higher retention rates

# Output
- Charts in R
- Summary report of findings
