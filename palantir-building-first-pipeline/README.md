# Key Insights
- Chaining joins are commonly used when needing to integrate data from several sources
- Materializing outputs (the process of storing results of a data transformation 
or join operation as a new dataset) is beneficial when dealing with large data transformations 
since it allows for breaking down the pipeline to use the results
