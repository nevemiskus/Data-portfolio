# Palantir - Speedrun: Your First End-to-End Workflow 

# Objective
Your company acquired one of its competitors. The IT unification project won't 
start for another year, so the team is working with two different systems. 
The goal is to create an operational tool for the fulfillment department that connects to both IT systems. 

# Tools Used
Foundry

# Data
Provided csv files 

# Analysis Steps
- Uploading data to Foundry 
- Cleaning and transforming the data
- Creating the ontology
- Building the workshop application
- Configuring actions
- Testing application 

# Key Insights
- Join the datasets with the master customer list and union them so that there is a single data set containing all orders
- The ontology is a relational "digital twin" of the business comprised of Objects. Once an Object is created for one 
use case, it can be reused for other use cases
- Workshop tool is used for quickly prototyping and creating applications that leverage the ontology
- Can create Actions to be performed on Objects or sets of Objects such as setting statuses, creating new orders
  
# Output
- Created an operational dashboard for the fulfillment department that serves as a single hub of information 
- Earned Foundry and AIP Builder Foundations Badge
