# Palantir - Speedrun: Your First AIP Workflow Analysis

# Objective
Fictional course in which a charity is expanding access to medication to underdeveloped regions. Joined a team
focusing on Tuberculosis.  With a large volume of studies about the disease, I use the team's access to AIP 
and build a Foundry workflow to obtain answers to our most important questions. 

# Tools Used
Foundry

# Data
Provided articles 

# Analysis Steps
- Transform the data
- Configure the ontology 
- Create AIP logic function
- Build interactive workshop app 

# Key Insights
- Learned to take PDF documents as an input, transform them into chunks, while taking the most significant entities 
from the chunks using an LLM
- Using the knowledge graph to investigate relationships between entities 

# Output
- Interactive workshop app answering questions about Tuberculosis by pulling information from the originally provided articles
